# S3Sync

S3Sync — экспериментальный клиент на C# для синхронизации через S3-совместимое хранилище. При каждом изменении клиент выбирает, отправить файл целиком или сохранить бинарную разницу с предыдущей версией. Чем дольше накапливаются дельты, тем больше объектов приходится читать при восстановлении.

| Эксперимент      | Что сравнивали                                                                                                                                                      |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Один файл SQLite | 500 375 552 байта, 240 изменений. Фиксированные пороги 2 и 4 и адаптивный порог от 2 до 4. Чтение начальной версии и далее через каждые 20 изменений.               |
| Группа файлов    | Отдельная база SQLite и 120 переходов истории исходников Zstandard. Для полных серий добавлен порог 3. У zstd два режима чтения — каждой версии и каждой двадцатой. |

На продолжении истории SQLite (версии 61–240) порог 3 дал на 6,70% меньше отправленных и скачанных байтов, чем порог 2. На zstd все четыре политики сохранили одну полную копию и 120 дельт. Для чтения последней версии понадобилось 122 запроса GET.

Эксперименты выполнены на Ubuntu с SeaweedFS. Клиент строит дельту Octodiff до шифрования. Для защиты пакетов используются X25519 и ML-KEM-768, AES-256-GCM и две подписи — Ed25519 и ML-DSA-65. Во всех сравниваемых политиках защита одинакова.
